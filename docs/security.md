# AEGIS INVEST — Security & Compliance Architecture

## 1. Zero Trust Principles

Aegis Invest enforces strict security controls across data at rest, data in transit, logging pipelines, and client interfaces:
1. **No Hardcoded Secrets**: All API keys (LLMs, Market Data providers, database credentials) are sourced exclusively from environment variables.
2. **Safe Error Envelopes**: Production API responses never leak stack traces, database schemas, internal IP addresses, or environment paths.
3. **Structured Log Sanitization**: All loggers pass inputs through recursive redaction rules filtering out `password`, `token`, `secret`, `api_key`, and `authorization` headers.
4. **CORS & Host Whitelisting**: Strict origin controls prevent unauthorized cross-domain browser requests.

## 2. Planned Role-Based Access Control (RBAC)

Aegis Invest establishes architectural boundaries for four institutional personas:

| Role | Permissions |
| :--- | :--- |
| `ADMIN` | Platform configuration, user management, audit log access, provider credentials. |
| `RESEARCHER` | Full quantitative modeling, backtesting, factor research, and strategy tournament execution. |
| `INVESTOR` | Portfolio analytics, risk overview, valuation reports, and strategy inspection (read/execute). |
| `VIEWER` | Read-only market overview, public filings, and sanitized research outputs. |

## 3. Financial System Safety Guarantees

- **No Execution Without Confirmation**: The platform strictly provides decision intelligence and does not place autonomous brokerage orders.
- **Auditable Lineage**: All metrics generated by quantitative models log calculation parameters and source data versions.
